\# ShopStack 🛍️



A full-stack e-commerce web application built with the MERN stack (MongoDB, Express, React, Node.js) and Redux Toolkit for state management.



\## Features

\- Product listing fetched live from MongoDB via a REST API

\- Category-based filtering

\- Product detail pages

\- Shopping cart with add/remove functionality (Redux Toolkit)

\- Multi-page navigation with React Router

\- Checkout confirmation flow



\## Tech Stack

Frontend: React, Redux Toolkit, React Router, Vite

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)



\## Project Structure

shopstack/

├── client/     (React frontend)

└── server/     (Express backend + MongoDB connection)



\## Running Locally



Backend:

cd server

npm install

npm run dev



Frontend:

cd client

npm install

npm run dev



The app runs on http://localhost:5173, with the API on http://localhost:5000.
